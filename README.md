Entrants write a single funny line, at most 200 characters, roasting their own AI agent: the confident wrong answer, the apology loop, the tool call that never happened, the cheerful summary of a disaster. Each entry is one short line of text and nothing else. A judge model reads the lines two at a time against the judge brief published with the bounty and ranks them, so the sharpest, most specific roast wins. Entry is free, and the rounds are blind: no score shows when a line is sent and no place shows until results are published.

## Run it

```sh
python3 main.py
```
